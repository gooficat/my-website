# So you don't have any hobbies

And you want to do something with your time.

Heres some that actually lead somewhere:

- 3D Printing. The bar for entry is a bit high. But if you can put together a setup with some good deals you could make something worth selling. This one is very good if you pick up a side hobby of CAD design (3d modelling for practical stuff). I have a page about 3D printing.
- CAD / Modelling. Computer-heavy hobby. But you can do it on a cheap computer. Learn to use TinkerCAD, then download FreeCAD. Or if you already do programming, you could try OpenSCAD.
- Web development. You can make nice looking, original websites. None of that AI stuff. Do it all manually. You can edit them anywhere, and view them anywhere.
- Low level computer programming. Like the C language. You could get into compiler development or algorithms. Could even make your own OS.
- Woodwork. Either carpentry or sculpting. Takes up a lot of time and people will buy that stuff too. Very high skill ceiling.
- Metalworking / Jewelry making. Same description as the previous one lol
- Game development. Try doing it without a game engine for a real challenge that encourages creativity.
